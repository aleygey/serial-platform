# Serial Platform v0.9.6

Windows x64 工位可直接运行便携版。需要独立 CLI、TUI 或 MCP 适配器时可下载完整工具包。[Windows 便携 EXE](https://github.com/aleygey/serial-platform/releases/download/v0.9.6/serial-platform-v0.9.6-windows-x86_64.exe) · [Windows 完整 ZIP](https://github.com/aleygey/serial-platform/releases/download/v0.9.6/serial-platform-v0.9.6-windows-x86_64.zip)

## 串口输出

- 修复连续追加日志时文字轻微上下抖动的问题。终端依据所选字号和屏幕缩放对齐每行文字，切换显示器或缩放后也会重新对齐。
- 串口分栏为系统滚动条预留宽度，内容刚好超过一屏时仍保持原来的换行位置。高缩放或历史栏展开时，底部留白会随可用高度缩小，为最新一行留出空间。

## 在线检查更新

- 启动后在后台查询 GitHub 最新正式版，持续打开时每 24 小时检查一次。发现新版后，顶栏会显示版本入口，Windows x64 可点击下载便携 EXE。
- 「配置 → 应用 → 软件更新」显示当前版本，可以立即检查或关闭自动检查。离线时可以继续使用串口，恢复联网后可手动重试。

## 从 0.9.5 升级

先下载本版，结束当前串口任务并退出旧程序，再双击新的 EXE。已有配置和日志继续沿用。在线检查更新从 0.9.6 开始提供。之后下载新便携版时，同样在任务结束后自行切换。
