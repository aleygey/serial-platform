# Serial Platform v0.9.5

Windows x64 工位可单独下载便携版，双击打开串口控制台。使用独立 CLI、TUI 或外部 Agent 的工位可下载完整工具包。[Windows 便携 EXE](https://github.com/aleygey/serial-platform/releases/download/v0.9.5/serial-platform-v0.9.5-windows-x86_64.exe) · [Windows 完整 ZIP](https://github.com/aleygey/serial-platform/releases/download/v0.9.5/serial-platform-v0.9.5-windows-x86_64.zip)

## 窗口和应用设置

- 按住顶栏中间的空白区域可以移动窗口。右上角提供最小化、进入或退出全屏、关闭三个按钮，后端启动期间也可使用。
- 「配置 → 应用」按外观、字号、后端连接分组。界面和终端字号并排调整。连接正常时收起地址和启动选项，首次配置向导位于页面标题旁。

## 串口输出和 Agent 历史

- 手动滚到底或按回车后持续跟随新输出。展开历史栏时，最新行随分隔线上移。阅读旧输出时保留当前阅读位置。
- 动作和命令在轨道节点上标出回执状态。点击动作可展开明细，点击命令可定位串口回显。回执超时用黄色表示，连接中断、部分写入和 Run 中止用红色表示。
- 修复配置的提示符后带空白、或紧跟同一行带日期时间的设备日志时漏匹配的问题。绿色表示命令匹配到了配置的结束条件。

## 从 0.9.x 升级

结束当前串口任务，退出旧版后启动新版。沿用协议 v9、配置格式 3 和原有数据目录。若外部 Agent 单独配置了 `serial-mcp.exe` 的路径，也请更新该路径下的程序并重新连接，以使用新的提示符匹配规则。
