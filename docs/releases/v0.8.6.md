# Serial Platform v0.8.6

## 新功能与修复

- Macro Script v1：由 seriald 执行可复用命令脚本，支持条件、循环、等待、延时及输出匹配。MCP 提供 `macro_list`、`macro_save`、`macro_run`，替代公开的 `trigger`；保留简单批处理 `command_sequence`。
- TUI 与 App 可查看、编辑、保存和执行宏。临时执行不污染共享列表，新宏默认草稿，显式共享后才向其他 Agent 提供摘要；保存和执行核对修订版本。
- 串口始终由 daemon 统一仲裁。宏超时、取消、人工输入后停止后续写入，Agent 需重新读取上下文；旧提示符和命令回显不能冒充新的匹配证据。
- TUI 默认字面搜索覆盖当前打开会话已接收的完整 RX/显示历史，不再只查内存尾部；结果直接定位输出上下文，支持前后跳转和后台分页搜索。
- 人工命令历史持久化并在整个平台共享，不混入 Agent、宏或控制键；修正历史回填、光标、焦点和草稿恢复。
- TUI/App 增加灰字历史建议：行末右方向键接受，Enter 仅发送实际输入，Tab 候选只回填；修复 Unicode 编辑和 IME 场景。
- Agent 占用串口时，人工 Ctrl-D 透传 `0x04`，不追加 EOL，并触发 Agent 重新读取上下文。
- 机型配置在同页展开一级/二级列表，统一绑定与选中展示；修复 RAW 编辑控制序列及输入分流。
- MCP `read` 可按字面规则过滤完整输出行，默认关闭；不改变原始证据、游标或人工干预后的读取要求。

## 升级注意

- Wire protocol 升至 **v8**。请同时升级 seriald、serialctl、serial-mcp 和 App，不要混用 0.8.5 组件。
- 旧 `trigger` 调用需改为宏；命令统一使用串口 profile 的 EOL，无独立 `input` 工具。
- 默认全会话搜索为字面 RX/显示投影；正则、Run、TX 搜索仍明确限定内存范围。未接收到的数据不能被搜索，关闭 TUI 后不承诺恢复临时会话索引。
- #14 与 #19 继续暂缓，未修改 OpenCode 审批界面。

## 验证与已知边界

- 本机 Rust 688 项测试、Clippy、格式检查通过；App 86 项测试、类型检查、生产构建及 Electron 键盘交互验证通过。
- 宏串口链路使用 PTY 验证新旧输出边界、人工中断、取消、超时与防重复写；搜索验证超过内存历史范围及百万命中分页。
- 未冒充真实 DUT 或 Windows 物理 COM 验收；尚无 GB 级长期高吞吐基准。宏匹配不支持任意终端重绘作为可靠证据，具体边界见 [Macro Script v1](../MACRO_SCRIPT_V1.md)。
- macOS App 仍未进行 Developer ID 签名或 notarization。

四个平台发行包均包含 Rust CLI/TUI/MCP/daemon 和对应桌面应用；使用同一 Release 的 `SHA256SUMS` 校验下载文件。
