# Serial Platform v0.9.1

Windows x64 用户下载 `serial-platform-v0.9.1-windows-x86_64.exe`，双击即可打开控制台。便携版自带串口服务。需要单独使用 TUI、CLI 或 MCP 适配器时，请下载同版本 ZIP。

## 桌面控制台

- 持续刷日志时，串口输出分批刷新。终端按需显示可见记录，查找仍可定位到当前缓冲区中的早期输出。发送命令后可立即输入下一条，上一条命令的回执会保留新的草稿。
- 单独启动 App 时会显示串口日志恢复进度。只要自有后端仍在恢复日志，App 就会继续等待，恢复后自动连接。
- 拖动已打开分栏的标题到另一栏即可交换位置。左侧串口可以互换顺序，也可以拖入工作区增加分栏。各栏保留自己的输入和历史。
- 在「配置 → 应用 → 外观」可将终端字号设为 10–28 px。字号同时作用于串口输出和命令输入，重启后保留。
- 串口机型选择器区分「机型系列」与「具体型号」，可跨系列搜索。选定具体型号后才写入绑定。
- 移除 Agent 演示窗口、回放和自动生成的示例方案。外部 Agent 通过 Serial MCP 实际接管串口时，输入框上方显示当前命令说明和任务历史。

## 从 0.9.0 升级

退出旧桌面应用后打开新版即可。0.9.1 沿用串口协议 v9、配置 schema 3 和原数据目录。已有串口配置、机型、宏、日志和命令历史继续使用。已有桌面偏好沿用原值，首次设置前的终端字号为 13 px。
