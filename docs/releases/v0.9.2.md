# Serial Platform v0.9.2

Windows x64 用户可直接打开便携版 `serial-platform-v0.9.2-windows-x86_64.exe`。完整 ZIP 还附带独立的 CLI、TUI 和 MCP。

- 桌面控制台按键盘顺序发送每一次回车，包括长按和等待上一条写入确认期间的输入。每次发送独立记录结果。空回车不会触发整段历史刷新。
- 烧录进度支持回车覆盖行首、退格和清除行尾。滚动条覆盖当前串口已加载的全部输出。拖到历史位置即可阅读，点「返回最新」恢复跟随。
- Agent 历史按执行实例显示宏名和状态。循环写入归入同一条宏记录，命令序列仍按步骤显示。终端输出和原始日志保留完整数据。
- App 单独启动时等待正在恢复日志的本地后端。串口实时连接就绪后即可输入，近期历史按串口在后台补齐。TUI 和桌面端可以连接同一个后端。

## 从 0.9.0 或 0.9.1 升级

结束当前操作后退出旧版，打开新版便携 EXE。协议沿用 v9，配置 schema 沿用 3。新版可读取原数据目录中的机型、宏、日志和命令历史。旧记录中缺少宏名时，历史显示保存的描述或宏 ID。
