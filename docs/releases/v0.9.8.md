# Serial Platform v0.9.8

## TCP 串口服务器

在首次配置或「配置 → 串口配置」中选择「添加 TCP 串口服务器…」，输入服务器的 IP 和端口，例如 `192.168.1.252:10001`。IPv6 使用 `[地址]:端口`。服务器应处于原始 TCP 透传模式，串口线参数在服务器端设置。启用自动打开后，网络断开会自动重连。设备可以沿用机型、记录和 Agent 控制。

## 机型选择

桌面控制台和终端机型列表均可用鼠标选择系列和具体型号。桌面列表立即展开和关闭。终端快捷机型菜单跳过了本地硬件枚举。

## 桌面更新

在设置中检查更新，点击「更新并重启」。应用按当前系统和架构下载正式版，核对大小及 SHA-256，退出桌面和它管理的本地服务，替换 Windows 便携 EXE、Linux AppImage 或 macOS 应用包，然后启动新版。应用所在目录需要可写。

从 v0.9.7 或更早版本首次升级时，先下载并打开新版桌面程序。以后可在应用内更新。独立部署的 `seriald`、CLI 或 MCP 服务需在其运行主机上单独升级。
