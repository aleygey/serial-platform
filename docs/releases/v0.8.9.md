# v0.8.9

## 修复与改进

- **Agent 历史失焦折叠（#32）**：离开历史面板时收起展开的 Run、命令和监控详情，并清理临时选择/高亮状态。保留原始历史记录。
- **TUI 宏超时与参数（#33、#36）**：运行前打开参数表单，按声明类型填写参数、预填默认值，并设置 1–120 秒的整体超时；校验通过后显式执行固定 revision。App 和 MCP 原有参数/超时能力保留。
- **宏计数器转换（#34）**：语言原本已支持 `i++`、`i--` 和复合赋值；新增显式 `str(integer)`，可以写 `cmd("show port " + str(i));`。整数溢出与字符串资源限制仍受保护。
- **MCP 句柄优先显示（#35）**：含 `run_handle` 的工具文本 JSON 将句柄放在第一项，避免共享宏目录或其他长内容先占满宿主展示前缀；完整 `structuredContent` 与其他字段保留。不宣称已定位或修改 OpenCode 自身的截断实现。

## 升级与范围

- 请配套更新 serial、seriald、serialctl、serial-mcp 与 App；使用新 `str(integer)` 宏需要新版后端。wire protocol 仍为 **9**，无需删除配置、宏或串口日志。
- 本版不含 App 视觉重构；该工作独立规划为 v0.9.0。
- #37 的独立共享调试命令目录后续单独设计；现有共享宏可以保存带参数的单条命令模板。本版不把“宏目录”宣称为完整的 debug 命令目录。
- #27 的真实 Windows 串口启动场景、GB 级长时间性能验证，以及 #28 的独立轮转 `.log` 自动归档不在本版完成范围。

## 验证与发布

验证结果以对应提交的 CI 为准。本版将构建与发布迁到 GitHub Actions 标准托管 runner：四个平台全部通过后才由短期 GITHUB_TOKEN 创建 annotated tag、校验资产和 SHA-256 并发布，旧 Jenkins 入口不再发布。无需本地构建节点或新增长期 token。自动化/模拟测试不等同于真实串口硬件验证。
