# Serial Platform v0.9.7

[Windows x64 便携 EXE](https://github.com/aleygey/serial-platform/releases/download/v0.9.7/serial-platform-v0.9.7-windows-x86_64.exe) · [Windows x64 完整工具 ZIP](https://github.com/aleygey/serial-platform/releases/download/v0.9.7/serial-platform-v0.9.7-windows-x86_64.zip)

## 双栏串口输入

改善另一个串口持续输出烧录进度时，当前分栏打字和回车回显间歇性卡顿的问题。终端逐字符显示连续的 `#`，分栏分别更新各自的输出。可在输入诊断中查看空回车各阶段的耗时，以及普通文字输入到下一帧的耗时。

## 后端重启恢复

独立 HTTP MCP（默认 3211）会重新连接同一台重启后的 `seriald`（默认 3210）。后端就绪后，外部 Agent 可直接发起新的 Run。原有 Run 句柄和租约失效，已下发的命令不会重放。3211 的 `/health` 返回当前后端的启动标识。

## 从 0.9.6 升级

结束当前串口任务并退出旧应用，打开新的便携 EXE。机型、宏、串口配置和已有日志继续沿用。

单独运行 3211 的工位还需解压完整 ZIP，退出旧的 `serial-mcp.exe`，从新目录按原参数启动一次。使用统一入口的工位可以退出原来的 `serial.exe`，然后从新目录启动。之后同一后端重启时，MCP 可以自行恢复。
