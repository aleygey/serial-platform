# Serial Platform v0.9.0

## Windows 桌面版

Windows x64 用户下载本页的 `serial-platform-v0.9.0-windows-x86_64.exe`，双击即可打开串口控制台。应用内置 Electron 和本地串口后端。需要命令行、TUI 或单独配置外部 MCP 宿主时，下载同名 ZIP 并完整解压。两种下载提供同一个桌面应用，各文件的 SHA-256 见 `SHA256SUMS`。

## 控制台更新

- 将左侧串口拖到工作区即可并排查看多个终端。每栏独立保留命令草稿、机型选择和执行历史，拖动分隔线可调整宽度。
- 外部 Agent 取得串口控制权时，Matrix Orb 显示占用。输入框上方跟随当前命令的描述，任务结束后显示本轮任务名和结果。时间线沿执行顺序展示动作与命令，手动展开的历史在切换页面后仍可继续查看。
- 首次配置向导通过串口、提示符和检查目标生成配置邀请。外部 Agent 通过新增的 `setup_proposal` 工具提交方案，用户确认后保存，并可运行一次心跳或状态检查。
- 配置和宏编辑采用分层导航，支持五种配色及深浅模式。桌面版可打开模拟串口示例，回放授权、命令执行和控制权释放。

## 从 v0.8.9 升级

退出旧桌面应用及自行启动的 `serial`、`seriald` 和 `serial-mcp`，保留原数据目录，使用同一系统账户启动新版。外部 MCP 宿主请切换到新版适配器并刷新工具列表。

串口配置沿用 schema 3，串口协议沿用 v9。已有串口及机型 Profile、宏定义和 revision、保留的原始日志与命令历史继续使用原有存储。已有桌面偏好会保留后端地址、选中串口和主题，并跳过首次向导。v0.8.9 的宏参数、超时与 `str(integer)` 语法继续可用。新向导的配置邀请需要 0.9.0 的后端和 MCP 适配器。
