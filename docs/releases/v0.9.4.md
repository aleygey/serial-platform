# Serial Platform v0.9.4

Windows x64 便携版可直接双击打开，应用内置 seriald。需要命令行、TUI 或 MCP 时，可下载完整 Windows ZIP。[下载桌面 EXE](https://github.com/aleygey/serial-platform/releases/download/v0.9.4/serial-platform-v0.9.4-windows-x86_64.exe)

## 人工输入

- 修复按回车后旧文字重新出现在输入框的问题。连续输入下一条命令时，从空输入框开始。发送遭拒时仍可恢复原草稿。
- 常规单次提交只同步一条已确认的人工历史记录。连续提交导致历史版本跳跃时，应用会补读。输入框补全最多请求两条候选，打开历史菜单可查看最多 50 个匹配项。
- 切换串口分栏时只同步偏好设置，避免通过窗口重复传输并处理各串口的整份缓存。

## 区分打字卡顿和回显延迟

点击串口标题右侧的波形按钮打开「输入诊断」。键入文字时，面板会显示输入事件至下一帧的最近一次耗时，以及最近 16 次以内的最高值。回车后，表格中的「首包」表示从发出命令到桌面主进程看到第一个串口数据包。设备主动输出的日志也可能成为首包。

原「上屏」分为三段，单位为毫秒。

| 列 | 测量区间 |
| --- | --- |
| 到窗 | 主进程收到首包，到窗口处理这批数据 |
| 更新 | 窗口收到数据，到 React 将终端内容更新到页面 |
| 等帧 | 终端更新，到下一次画面刷新回调 |

遇到停顿时，在同一串口各试一次空回车和一条熟悉的只读命令，等提示符出现后点「定格」。拍下表头、两行数字和文字输入耗时即可。诊断只在当前分栏里保留时间和输入类型，关闭面板即停止采样。

## 从 0.9.x 升级

结束当前串口任务，退出旧版，再打开新版 EXE。沿用原有的协议 v9、配置格式 3 和数据目录，已有的串口设置、机型、宏和日志均可继续使用。
