# Serial Platform v0.9.3

Windows x64 可直接运行便携版 `serial-platform-v0.9.3-windows-x86_64.exe`。完整 ZIP 另含独立的 CLI、TUI 和 MCP。

- 在某个分栏发送命令或空回车，会立即回到该串口的最新输出，继续跟随设备回显。浏览其他分栏的历史位置会保留。
- 终端跨接收包解码 UTF-8，正确处理提示符中的不可见控制字节和跨包转义序列。原始串口日志仍保留设备发送的字节。
- 点击「Agent 执行历史」标题即可收起，再点输入框上方的状态栏即可展开。每个分栏分别记住选择，任务继续时仍显示当前动作。
- 「配置 → 应用 → 外观」可分别调整界面字号和终端字号，重启后继续使用。界面字号用于导航、配置和历史，终端字号用于串口输出和命令输入。
- Windows 串口驱动队列读空后立即上报已收到的数据，省去一次额外的轮询等待。桌面端优先交付人工输入后的首个接收包，终端复用已渲染的输出块，并减少普通收发期间的 Agent 历史重绘。

## 在工位采集回车延迟

在串口标题右侧点击波形图标「输入诊断」，在设备可正常接收输入时连续按几次回车，等提示符出现后点击「定格」。拍下面板的表头和数值即可。面板显示最近八次输入的时间、串口名、版本和缓存事件数，采样仅在当前窗口内保留。

| 列 | 计时范围 |
| --- | --- |
| 排队 | 按键事件产生到输入处理开始 |
| 分发 | 输入处理开始到桌面主进程发出写入请求 |
| 确认 | 发出请求到后端确认本次人工写入 |
| 首包 | 发出请求到桌面端收到该次写入之后的首个串口数据包。设备主动日志也可能先到 |
| 上屏 | 收到该包到终端界面更新后的下一帧回调 |
| 总计 | 从按键到首包对应的界面帧 |
| 提示符 | 从按键到终端匹配当前机型的 Shell 或 U-Boot 提示符并进入下一帧。未配置或未匹配时留空 |

时间单位为毫秒，确认和首包可以先后交错。「—」表示尚无该项观测，星号表示多次输入共用同一个首包。

## 从 0.9.x 升级

完成当前串口任务并退出旧版，打开新版 EXE 即可。协议沿用 v9，配置 schema 沿用 3，已有机型、宏、串口日志、历史和终端字号可以直接沿用。
